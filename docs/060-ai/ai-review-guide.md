# BobFull Human 이해·Review 응답 가이드

이 문서는 Human 이해 질문과 답변 검토 기준을 다룬다. 최신 Head AI Review의 결함 등급·댓글 형식·재검토 절차는 `skills/bobfull-pr-review/SKILL.md`가 단일 기준이다.

## 1. 사용 시점

- Issue에서 Human 결정이나 이해 확인이 필요할 때
- Refactor Learning Mode의 Human 답변을 검토할 때
- PR 검토 수준에 따른 Human 이해 질문을 작성할 때
- Human 또는 외부 Review 의견의 처리 방향을 판단할 때

일반 구현, PR 본문 작성, AI Review만 수행할 때는 이 문서를 선행 로딩하지 않는다.

## 2. 공통 질문 원칙

- 신입 백엔드 기술면접의 기본 개념 수준으로 작성한다.
- 코드 줄·클래스·메서드 이름 암기보다 실행 흐름과 선택 이유를 묻는다.
- 실제 Issue·Diff·검증에 근거하고 일반 이론 문제를 만들지 않는다.
- 이미 답한 질문을 다른 단계에서 그대로 반복하지 않는다.
- Human 답변 원문을 AI가 대신 작성하거나 덮어쓰지 않는다.
- 정책·API·DB·상태·권한·보안·트랜잭션 결정을 이해 질문으로 우회하지 않는다.

## 3. Issue 단계

일반 Feature Issue는 학습 질문을 구현 Gate로 사용하지 않는다. 실제 Human 결정이 필요한 경우에만 질문한다.

Refactor Learning Mode의 적용 대상, 최초 중단, 질문 3축과 재개 조건은 `ai-workflow.md`만 따른다. 이 문서에서는 질문 난이도와 답변 검토 방식만 적용한다.

Human 답변은 다음처럼 검토한다.

- `일치`: 현재 코드·문서·Issue 계약과 핵심 의미가 맞음
- `보완 필요`: 중요한 오해나 누락이 있어 추가 설명·재질문 필요
- `미작성`: Human 답변이 없음

AI는 `AI 보완 설명`에 실제 코드 흐름과 테스트 근거를 적는다. 답변이 불충분하면 필요한 부분만 다시 질문하며 구현을 진행하지 않는다.

## 4. PR Human 이해도

현재 PR Human 이해 질문 체계는 이 작업에서 변경하지 않는다.

### 기본 검토

질문은 `0개`다.

문서·설정·단순 CRUD·기존 패턴 반복에는 질문을 만들지 않는다.

### 강화 검토

질문은 정확히 `3개`다.

1. 핵심 실행 흐름과 주요 분기
2. 가장 중요한 기술 개념과 실제 적용 위치·이유
3. 설계 선택 이유, 주요 실패 처리와 남은 한계

강화 질문 완료 여부는 현재 Merge Gate가 아니다. Refactor Learning Mode에서 Issue 단계의 3개 질문을 이미 완료한 PR은 같은 질문을 반복하지 않는다. 강화 검토가 필요하면 최신 Diff·검증 결과·남은 한계처럼 PR에서 새로 확인할 내용을 묻는다.

## 5. 답변 기록

Human 답변과 AI 검토를 구분한다.

```text
Human 답변:
AI 답변 검토: 일치 | 보완 필요 | 미작성
AI 보완 설명:
Human 최종 확인: 이해함 | 추가 설명 필요 | 동의하지 않음
```

- AI 기준 설명은 절대적인 모범 답안이 아니라 현재 확정 계약과 구현의 설명이다.
- Human 최종 확인을 AI가 대신 체크하지 않는다.
- 질문이 필요 없는 기본 검토에서는 `해당 없음: 기본 검토`를 유지한다.

## 6. Review 의견 처리

최신 Head와 실제 코드 근거를 먼저 확인한다.

- 범위 안 결함: 수정하고 필요한 검증을 다시 실행
- 설명·확인 요청: 코드와 테스트 근거로 답변
- 정책·API·DB·권한·트랜잭션 결정: Human 판단 요청
- 근거 없는 범위 밖 제안: 반영하지 않고 이유 기록

BLOCKER·MAJOR·MINOR·SUGGESTION 판정과 Merge 영향은 `skills/bobfull-pr-review/SKILL.md`를 따른다. 현재 Merge Gate는 `.github/pull_request_template.md`를 기준으로 한다.

## 7. 금지 사항

- Human 답변 대리 작성
- 이전 Head의 답변 검토를 최신 Diff에 근거 없이 재사용
- 중요하지 않은 질문으로 구현·Merge 지연
- PR 질문을 Refactor Learning Mode의 Issue Gate로 오인
- 질문을 통해 정책·보안·데이터 결정을 AI가 확정
