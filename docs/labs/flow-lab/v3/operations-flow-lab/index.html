    검증 범위

    #169(App HA + AWS Redis cross-instance), #192(Kafka Async 비교·Consumer scaling·통합 모놀리스 결정), #274(Outbox+Async vs Outbox+Kafka 통제 비교), #258(messageId Partition Key), #251(Rule Fast Path), #266(Split Message Rule Context)은 실제 검증 결과를 Ch3·Ch5·Ch6에 반영했습니다. #191은 별도 재생 Chapter 대신 측정 결과에 따라 Auto Scaling 미도입으로 확정하고 ADR 0015에 기록했습니다.

    • #169 — verified, measured · App HA + AWS Redis cross-instance → Ch3 AWS_CROSS_INSTANCE_NORMAL 반영
    • #192 — measured · Async/Kafka·Consumer scaling·통합 모놀리스 유지 결정 → Ch5 반영
    • #274 — measured · 동일 Transactional Outbox 조건의 Async/Kafka 통제 비교 → Ch5 반영
    • #258 — measured · messageId Partition Key → Ch5 Kafka 도입 의사결정 Lab 반영
    • #251 — measured · Moderation Rule Fast Path → Ch6 CLEAR_FLAGGED_FAST_PATH 반영
    • #266 — verified + Provider 6-case observation · Split Message Rule Context → Ch6 SPLIT_MESSAGE_EVASION 반영
    • #191 — measured and rejected · App Auto Scaling 미도입, Active App 2대 유지 → 대표 ADR 0015
